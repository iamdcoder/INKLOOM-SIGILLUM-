# Requirement Source Attribution

The requirement register is derived from the consolidated `SIGILLUM_Plan` and follows its 16-phase map. The master plan combines the original product proposal, technical blueprint and additional engineering/UX recommendations. The current register therefore marks the consolidated master plan as its source; it does not invent a line-by-line attribution to the unavailable underlying source pages.

Where a requirement is added beyond the consolidated master plan in a later phase, mark its source explicitly as `Added recommendation`, record the rationale in the decision log, and obtain a test ID and phase assignment before implementation. Do not silently replace or delete a requirement.
