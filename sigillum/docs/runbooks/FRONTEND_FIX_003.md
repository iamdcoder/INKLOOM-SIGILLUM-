# Frontend Fix 003

This patch addresses the remaining diagnostics reported after Frontend Fix 002.

## Changes

- `apps/web/app/reviews/[id]/page.tsx`
  - Separates asynchronous review retrieval (`fetchReview`) from state application (`load`).
  - The initial `useEffect` subscribes to the asynchronous promise and writes React state only from its completion handlers, rather than calling a state-mutating loader synchronously from the effect body.
  - Adds an effect cleanup guard so a late response cannot update an unmounted review page.
  - Uses explicit null checks when selecting the preview URL and preview error for the active content version. This allows TypeScript to narrow the values safely.

## Apply

Extract `INKLOOM_SIGILLUM_FRONTEND_FIX_003.zip` into the existing `sigillum` project root (the directory containing `apps`, `backend`, and `README.md`) and overwrite the target file.

## Verify

From `apps/web`, run:

```powershell
npm run lint
npm run typecheck
npm run build
```

Do not treat this patch as verified until all three commands complete successfully on the project machine. Preserve the `package-lock.json` generated by the successful install.
